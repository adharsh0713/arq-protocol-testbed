# Experiment Results

The release repository tracks the final attempted-run CSV, its failure-aware aggregate summary, and the configured-versus-realized fault comparison. Individual run directories (process logs, JSON reports, and reconstructed file copies) are generated under `runs/` and are intentionally excluded from the clean source archive because they are bulky and reproducible from the CSV, seed, fixtures, and methodology. Preserve a separate raw-run archive when preparing an audited final research release.
